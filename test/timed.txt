# machine. They run one after another, on a quiet machine:
#   node test/run-all-tests.js --timed
#   node test/repro/run-repro.js --timed
#   node test/integration/run-all-integration-tests.js --timed
# Every other run leaves them out with --without-timed (CI does). One test per
# line, "<name>  # <reason>": a suite file by its name, the others as
# repro/<name> or integration/<name>. A line without a reason, naming a file that
# isn't there, or naming one no runner finds by name, stops the run. See
# test/README.md.
